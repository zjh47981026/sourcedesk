with a source.

  1. Add documents

    Text-based PDF, TXT and Markdown files are split into passages, preserving PDF page numbers.

  2. Choose your sources

    Only checked documents are searched for each question.

  3. Ask and verify

    With a local AI model configured, SourceDesk drafts an answer with citations. Otherwise it shows matching passages as source search.

Documents stay in this app's temporary browser session. Restarting the app or a session expiring removes them. Scanned PDFs need OCR. Retrieval currently works best for English text.

AI generation requires a running local Ollama model. See the project README for setup. A ChatGPT Pro browser subscription is not used as an API.
